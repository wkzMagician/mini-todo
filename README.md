## 关于 Mini Todo

Mini Todo 面向希望快速记录和整理日常任务的人。打开应用后即可添加任务，再用「今天 / 本周 / 本月 / 今年」切换关注范围；桌面端还可以驻留系统托盘，需要时快速回到任务列表。

它适合用来管理个人待办、短期计划和周期性提醒。界面保持简洁，常用操作集中在主界面，不需要先建立复杂的项目结构。

## 功能亮点

### 按时间范围整理

将任务放入今天、本周、本月或今年的视图，按当前关注的时间范围查看清单。

### 快速完成与撤销

添加任务后可以直接编辑内容，点击完成即可归档；如果误操作，可以使用撤销恢复刚刚完成的任务。

### 清晰的任务编辑

任务可以随时修改标题，也可以在不同时间范围之间调整归属，让清单始终保持清晰。

### 跨设备同步

通过 WebDAV 连接自己的同步服务，在多台设备之间保持任务一致；支持自动同步，也可以在设置中手动立即同步。

### 桌面端常驻

Windows、macOS 和 Linux 桌面端支持系统托盘与单实例运行，并可按需开启开机自启动。关闭窗口后，应用可以继续安静地驻留在托盘中。

### 中文与 English

内置中文和 English 两种界面语言，可在设置中切换。

## 快速开始

### 直接使用

仓库当前包含 Windows 和 iOS 的构建产物，位于 `dist/` 目录。项目暂未配置公开下载页；如果你是普通用户，可从项目发布页或维护者提供的安装包开始使用。

### 从源码运行

需要先安装 Flutter，并准备好目标平台的开发环境。然后在项目根目录运行：

```bash
flutter pub get
flutter run -d windows
```

将 `windows` 替换为 Flutter 当前可用的设备标识，即可运行到其他平台。查看设备列表：

```bash
flutter devices
```

## 同步与设置

打开应用右上角的设置入口，可以配置：

- 界面语言：中文或 English；
- 开机自启动：桌面端可选；
- WebDAV 同步：填写 WebDAV 地址、用户名和密码；
- 立即同步：手动触发一次同步并查看同步状态。

同步数据使用 `MiniTodo` 作为远端数据集。请通过 Mini Todo 管理同步内容，不要直接修改 WebDAV 中的内部文件。

## 参与开发

欢迎提交问题反馈和改进建议。修改代码后，请在项目根目录执行以下检查：

```bash

```

项目使用 Flutter 构建，应用入口位于 `lib/main.dart`；业务功能主要位于 `lib/features`，应用组合与平台生命周期代码位于 `lib/app`。
